# NY Breakout Autopilot (Bybit)

Автопилот по стратегии из дашборда «NY Breakout Terminal»: пробой и ретест вчерашнего
максимума/минимума (PDH/PDL) на открытии Нью-Йорка. Монеты: BTC, ETH, SOL (USDT perpetual).
Дашборд — страница сервиса на Railway, на ней живые данные бота и честный бэктест.

## Правила

- Окно: **16:30–17:30 по Киеву** (9:30–10:30 Нью-Йорк), только будни.
- LONG: закрытая 1m свеча коснулась PDH (±0.12%), закрылась выше и сильная (тело ≥ 50% свечи).
  SHORT — зеркально от PDL. Не больше 1 сделки на монету в день.
- Риск **1% баланса**, стоп **0.3%** от входа. На **+2R** стоп в безубыток (с учётом комиссий),
  тейк **+3R**.
- **Только лимитные ордера**: вход лимитками с догоном (не дальше 0.3R от цены сигнала),
  на бирже сразу стоят тейк (лимитка) и стоп-лимит. Если цена проскочила стоп-лимит —
  бот закрывает лимитками с догоном.
- Комиссии ≈ 0.37R на сделку (0.055% × 2 при стопе 0.3%) — учтены в бэктесте.

## Railway

Variables:

| Переменная | Значение |
|---|---|
| `BYBIT_API_KEY`, `BYBIT_API_SECRET` | ключ Bybit (право Contract Trade, без вывода) |
| `BOT_ARGS` | необязательно, например `--risk 0.5` или `--symbols BTCUSDT,ETHUSDT` |
| `CONTROL_KEY` | пароль для кнопок на странице (рекомендуется) |
| `START_PAUSED` | `1` — после запуска ждать кнопку «Старт» |
| `STATE_PATH` | `/data/state.json`, если подключён Volume в `/data` (журнал и открытые сделки переживут редеплой) |

Settings → Networking → Generate Domain — ссылка на дашборд.

При перезапуске сервиса позиции **не закрываются**: на бирже стоят тейк и стоп-лимит, после старта
бот продолжит вести сделку (нужен Volume, иначе бот не вспомнит её параметры).

## Параметры (BOT_ARGS)

| Флаг | По умолчанию | |
|---|---|---|
| `--testnet` | выкл | учебный счёт |
| `--dry` | выкл | только сигналы, без ордеров |
| `--symbols` | BTCUSDT,ETHUSDT,SOLUSDT | монеты |
| `--risk` | 1 | риск на сделку, % баланса |
| `--sl` | 0.3 | стоп, % от входа |
| `--be-r` / `--tp-r` | 2 / 3 | безубыток и тейк в R |
| `--touch` | 0.12 | касание уровня, % |
| `--strong-body` | 0.5 | тело сигнальной свечи (0 = не проверять) |
| `--trades-per-day` | 1 | сделок на монету в день |
| `--session-start` / `--session-min` | 09:30 / 60 | окно по Нью-Йорку |
| `--max-leverage` | 20 | потолок плеча |
| `--entry-slip-r` | 0.3 | не догонять вход дальше X×риска |
| `--stop-limit-slip` | 0.15 | стоп-лимит: лимит за триггером, % |

## Файлы

- `strategy.py` — правила стратегии и бэктест (общие для бота и страницы)
- `ny_bot.py` — автопилот
- `bybit_util.py` — работа с Bybit
- `web.py` — сервер страницы и API, `dashboard.html` — дашборд

Локально: `pip install -r requirements.txt && python ny_bot.py --testnet`, страница http://localhost:8080
